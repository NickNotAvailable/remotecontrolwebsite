# Placeholder media

Every clip here is a stand-in for real portfolio work. All brand names, project titles and credits
shown on screen are fictional. The footage is openly licensed. It was trimmed, colour-graded, looped
and re-encoded by `scripts/make-placeholder-media.sh`.
